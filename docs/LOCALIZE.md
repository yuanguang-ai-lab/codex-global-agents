# 本地化与个性化安装指南

本指南面向希望安装模板的用户及其 Codex。只在用户明确要求安装、合并或更新个人全局规则时执行；普通仓库阅读不触发安装。这是操作说明，没有附带自动执行脚本。

`AGENTS.md` 是通用规则模板，`README.md` 和本指南是安装资料，不要把安装说明整篇拼进全局规则。脱敏版不需要恢复原作者删掉的信息：应使用当前用户自己的环境事实和选择。

## 1. 确认目标环境

先确认用户希望配置的是本机桌面、CLI、远程主机还是容器中的 Codex。工具当前所在环境未必就是目标环境；不要把容器中的安装成功说成用户电脑已配置成功。

在可访问的目标环境中，识别当前用户的主目录和 Codex 配置目录。配置了 `CODEX_HOME` 时使用其实际值；否则默认是该用户主目录下的 `.codex`。不要套用原作者路径，不要为安装模板重设 `HOME`、`USERPROFILE` 或 `CODEX_HOME`。如果应用与终端使用不同运行环境，应分别确认目标，而不是假定它们共享配置。

只读取与本次安装有关的信息。检查目标目录中的 `AGENTS.md`、`AGENTS.override.md`，以及判断有效指令来源确实需要的配置项；不要打印完整环境变量、凭据配置、日志或会话历史。

## 2. 哪些内容如何个性化

| 内容 | 从哪里确定 | 如何处理 |
|---|---|---|
| 全局安装路径 | 目标环境的实际配置目录 | 在本机展开真实路径，用于安装与验证；通常不必把绝对路径写回规则正文 |
| 工作区、输出与备份位置 | 用户现有项目和明确选择 | 优先沿用；没有需要时保留通用表述，不凭空新建固定目录体系 |
| 项目根目录 | 已选工作目录及必要的 Git 检查 | 不把模板仓库或当前临时目录当作用户的全部项目根目录 |
| 语言和回复习惯 | 当前用户要求、已有个人规则 | 明确时直接保留；只有冲突会改变结果时再询问 |
| GitHub 账号、仓库和操作范围 | 用户请求及所涉及仓库的已核实信息 | 安装规则本身不需要登录或试推送；模板不授予任何账号权限 |
| 服务地址、域名、端口 | 仅在相关任务确实需要时查阅该用户配置或询问 | 本模板没有必须填写的服务地址，不为“本地化”发明或添加端点 |
| 密钥、令牌、密码 | 原有安全配置机制 | 不写入 AGENTS.md、报告或分享仓库，不要求用户粘贴到聊天 |
| 技能、子代理、计划任务与 handoff | 当前可用工具和已有项目约定 | 不假定某插件已经安装；缺少能力时保留适用的通用约定，不自动安装或启用 |

可验证的事实直接识别，已有偏好直接沿用，无法确定且会影响结果的选择集中询问。不得从这个仓库的历史版本还原原作者的地址、身份或预授权，再当作新用户的默认设置。

## 3. 备份并合并

- 对将被修改的文件创建有日期、可恢复的本地备份，记录原路径；备份不提交到分享仓库。
- 没有现有规则时，以模板为基础适配。有现有规则时，保留个人偏好、已确认授权和更严格的安全边界，合并重复项；只处理本次范围内的冲突。
- 不预设“用户已授权所有仓库操作”，不增加 GitHub 账号、发布或支付权限。安装请求只授权所述规则配置工作。
- 如果 `AGENTS.override.md` 存在，它优先于同级 `AGENTS.md`。先说明哪个文件生效；未经具体授权，不删除或覆盖 override。可以先准备合并结果，必要时询问要应用到哪个有效文件。不能在新模板仍被遮蔽时声称已经生效。
- 保持文件名为 `AGENTS.md`，不要误用 `Agent.MD`。除非用户另有要求，本次仅处理全局规则，不修改业务项目的局部文件，不切换模型、审批策略、插件、hooks 或远端配置。
- 本地个人版可以包含确有必要的个人约定；以后向分享仓库贡献改动时，只导出重新检查过的通用内容。

需要的常规本地读写和检查在安装请求范围内推进，无需逐步重复确认。目标环境无法访问、实际生效文件不明确或合并会改变用户重要边界时，先完成不受阻的准备，再说明具体问题。

## 4. 验证与交付

检查最终文件、差异和备份，确认规则没有遗漏、意外放宽或未处理的占位符。对路径只验证本次真正需要使用的位置；对已经明确授权的范围按原义保留，不能通过尝试外部操作来“测试授权”。

在支持的 CLI 版本中，可以使用 `codex debug prompt-input` 检查预期规则是否出现在加载结果中，只报告必要标记，不分享完整提示输入。若工具不可用，核对文件与加载路径，并说明需要在目标环境的新任务中进一步确认；不要谎称完成运行验证。文件修改不会清除已有对话中的旧指令。

最后提供：实际安装位置、个性化项目及依据、保留的关键边界、备份位置、已做的验证与尚未验证的部分。若只生成了候选文件而未写入目标位置，应明确标为“待安装”。

加载机制依据：[OpenAI 官方 AGENTS.md 说明](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。本指南的安装流程是本仓库的建议，不能保证所有主机、版本或模型都自动执行成功。
